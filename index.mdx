<section className="mx-auto mt-16 max-w-7xl px-4 sm:px-6 lg:px-8">
  <div className="max-w-3xl">
    <h2 className="text-3xl font-semibold tracking-tight text-[#0A090C] dark:text-white">Get started with AURA</h2>
    <p className="mt-3 text-base font-light leading-7 text-[#3A344B] dark:text-[#CECECE]">
      From install to your first investigation in four steps. You need macOS or Linux and an API key for OpenAI, Anthropic, Gemini, Bedrock, or OpenRouter, or a local Ollama instance.
    </p>
  </div>

  <div className="mt-8">
    <Steps>
      <Step title="Install the CLI">
        The script picks a native package, Homebrew, or a direct binary for your platform. See [Installation](/aura/installation) for every method.

        ```bash
        curl -fsSL https://raw.githubusercontent.com/mezmo/aura/main/scripts/install.sh | bash
        ```
      </Step>
      <Step title="Generate a config">
        The wizard detects your provider key, offers a model shortlist, and writes a `config.toml` for an SRE orchestrator with three specialist workers. Your key stays in the environment, never in the file.

        ```bash
        aura init
        ```
      </Step>
      <Step title="Connect your tools">
        Start AURA, then add an MCP server from the built-in catalog (Mezmo, PagerDuty, Datadog, Kubernetes) or any server over HTTP, SSE, or stdio. You choose which workers see which tools.

        ```bash
        aura
        /mcp add
        ```
      </Step>
      <Step title="Put it to work">
        Restart `aura` to load the new server, then ask it something real: *Who is on call right now, and are there any open incidents?* The full walkthrough is in the [Quickstart](/aura/quickstart).
      </Step>
    </Steps>
  </div>

  <div className="mt-8">
    <CardGroup cols={3}>
      <Card title="Local quickstart" icon="terminal" href="/aura/quickstart">
        Install the binary, run `aura init`, connect an MCP server, and start asking questions.
      </Card>
      <Card title="Docker quickstart" icon="docker" href="/aura/quickstart-docker">
